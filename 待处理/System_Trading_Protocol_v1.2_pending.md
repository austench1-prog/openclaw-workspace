## 核心原则
用高标准"通用强约束"覆盖各平台细碎规则，降低 Agent 逻辑复杂度，提高账户安全性。

---

## 1. 交易日准入协议

- **全天假** → 系统锁定，不参与
- **半天假/早收盘** → 全天不参与
- **逻辑：** 只在完整的正规交易日参与，消除流动性不足和非对称波动风险

---

## 2. 时间窗口强制协议

- **统一强平死线：美东时间 16:00:00**
- 无论各平台规定是 16:15 还是 16:59，系统一律提前到 16:00 强制平仓
- **绝对禁止过夜：** 所有产品统一当日结清
- Agent 不再需要记不同品种的不同收盘时间

---

## 3. 风险边际协议

- **动态水位监控：** 实时计算当前净值与 Floor 的距离（不用静态余额）
- **止损优先原则：** 所有开仓必须附带 Bracket Orders，Agent 检测到未设止损 → 立即干预

---

## 4. Agent 决策简化流程

```
Step 1: 今天是完整交易日吗？ No → 停止
Step 2: 现在在 09:30-16:00 之间吗？ No → 拒绝开仓/强制清仓
Step 3: 账户在安全水位吗？ No → 触发保护
```
