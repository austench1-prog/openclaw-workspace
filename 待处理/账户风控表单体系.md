# 账户风控表单体系

适用对象分为三类：

1. **考试账户（Evaluation Account）**
    
2. **Funded Account**
    
3. **Live Account**
    

三类账户共用统一逻辑，但关注重点不同：

- **考试账户**：重点看“过关规则、合规性、达标条件”
    
- **Funded Account**：重点看“保账户、提款规则、风控约束”
    
- **Live Account**：重点看“真实资金风险、执行纪律、收益回撤控制”

# 四、三类账户的差异化重点

你们内部使用时，可以把三类账户理解成三种不同目标。

## 考试账户

核心目标是：

- **通过规则**
    
- **不违规**
    
- **完成考核**
    

关键关注：

- 盈利目标
    
- 最低交易日
    
- 是否算有效交易日
    
- 每日最大亏损
    
- Drawdown
    
- Contingency / 单日最大盈利限制
    
- 一致性规则
    

## Funded Account

核心目标是：

- **保账户**
    
- **稳提款**
    
- **不因违规失去资格**
    

关键关注：

- 回撤控制
    
- 每日亏损限制
    
- 提款规则
    
- 一致性要求
    
- 收益分成
    
- 行为合规
    

## Live Account

核心目标是：

- **真实资金安全**
    
- **长期收益稳定**
    
- **系统与执行可靠**
    

关键关注：

- 总体风险预算
    
- 单日/单周/单月回撤
    
- 仓位管理
    
- 多策略协同
    
- 应急预案
    
- 系统故障处理

# 六、给你一版更适合直接落地的字段结构

如果你要给团队统一填写，我建议三组表单都固定成这 8 个模块：

1. 基础信息
    
2. 收益/考核指标
    
3. 交易日与合规要求
    
4. 每日亏损限制
    
5. 盈利限制 / 锁盈机制
    
6. Drawdown / 回撤规则
    
7. 行为限制与系统限制
    
8. 执行摘要与当日检查项
    

这样不管是考试账户、Funded、还是 Live，大家填表和查表的习惯都会一致。
