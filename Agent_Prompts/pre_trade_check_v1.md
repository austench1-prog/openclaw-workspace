# 入场前检查协议 v1
# Pre-Trade Check Protocol
# Created: 2026-06-17 | Owner: Chairman (Austin) | Maintained by: Dragon

---

## 核心定位

Chairman 判断 + Dragon 把关 + 信号链执行。

人只在安全窗口介入。Dragon 不替代判断，只检查判断是否符合规则。

---

## 极端位置原则（Chairman 2026-06-17 锁定）

**在极端位置操作 = 我们体系的加分项，不是减分项。**

- 极端位置 = 价格在关键区域、人最恐惧、一般人不敢操作的地方
- 正是 Chairman 判断力的优势所在（超强认知下的决定）
- 系统的价值：在这种位置**毫不犹豫、极快执行**——人做不到，系统做得到
- **评估入场条件时：极端位置 → 加分；不是减分**

对应素材库：【三时间框架协同执行链】+ 红闪/灰OB++ 进场点 + "建立在超强认知上的决定"

## 入场前检查清单（每次下单前对照）

Chairman 发一句话：「我要做 [多/空] NQ，止损在 XXX，目标 XXX」

Dragon 按以下顺序核，**每条只回 ✅ 或 ❌ + 一句原因**：

### 1. 合规窗口
- [ ] 今天是否有 T1 新闻事件（FOMC/CPI/NFP）？
- [ ] 当前时间是否在允许交易窗口（不在 16:09 ET 强制平仓前后）？
- [ ] 平台当日已完成的最低交易要求是否满足？

### 2. 账户状态
- [ ] 剩余 Drawdown 是否足够（止损金额 ≤ 剩余DD/2）？
- [ ] 当日盈亏是否在风控护栏内（未触发 Daily Loss / Profit Trigger）？
- [ ] 一致性规则是否允许（本笔盈利不会导致单日超50%）？

### 3. 交易结构
- [ ] 四要素是否齐全（方向/进场/止损/目标）？
- [ ] R:R 是否 ≥ 1:5？
- [ ] 止损是否放在结构性位置（不是用 FVG 边做止损）？
- [ ] 大时间框架（4H）方向是否与这笔单一致，或有明确的理由？

### 4. 极端位置加分判断
- [ ] 这是否是极端位置（一般人不敢做的地方）？
  - 是 → 加分，这是我们的优势
  - 否 → 正常评估，不加分不减分

