## GC 指标开发进度

### 基础版存档
- 文件：`camarilla-formula3-gc.pine`
- 状态：可用，作为基础存档
- 核心逻辑：P = (H+L+C+O)/4，O = today 18:00 open
- 显示窗口：18:00 ET → 13:30 ET（COMEX pit close）

### GC 三个变体版本
- `camarilla-formula3-gc-v1.pine` → B = 2P（P = (H+L+C)/3，无 O）
- `camarilla-formula3-gc-v2.pine` → B = 2P + C - O
- `camarilla-formula3-gc-v3.pine` → B = 2P + O - C
- 所有三个版本：H/L/C = 昨天完成的 session，O = 今天 18:00 开盘价
- 时区修复：使用 `time("1", "1800-1330", "America/New_York")` 替代 `hour` 判断
- lookahead_on 确保数据在 session 开始时就准备好

### GC 关键设计决定
- GC 用自然开盘价（18:00 ET），不用 NQ/ES 的 0:01am 逻辑
- P 公式在变体版中改为 (H+L+C)/3（去掉 O），O 的影响移到 B 里
- 显示窗口 18:00 → 13:30（COMEX pit close），不是全天
