**交易区域A 内部笔级（Chairman 22:09 给的，区间=50点）：**

### 碰25% vs 没碰25% = 互斥（分水岭 = 回50%时手上有没有仓可减）
- 碰25% → 25%加了4手 → 回50%时有仓 → **减仓**（减3手）
- 没碰25% → 无仓可减 → **加仓**（加3手）

### ⚠️ 必须展开到笔级，每笔都有成/败分叉，盈亏一笔不吞
- 区域A 不管整体成/败，内部 A1~A5 已成交的盈亏都已实现，不能跳过直接上3楼（Chairman 22:34 纠正）

### ⚠️ 碰25%路径的亏损侧是分层的（Chairman 22:39 + 22:42 补）
碰25%加满5手(1+4)后若不反弹往下走：
- **较坏：** 破第一个STOP → A区域5手全损，1楼底仓还在
