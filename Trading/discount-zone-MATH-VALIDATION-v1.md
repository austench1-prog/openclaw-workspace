## 0. 这份文档要回答的核心问题

> **我们这套"复杂的多策略头寸管理"，在数学上到底成不成立？跟"直接用单一1:5在大框架上做一笔"相比，哪个更优？**

Chairman 的通俗版（模型灵魂）：
> **"我们是在一个大的生意里，顺手做了一点小的生意。"**
> - 大生意 = 底仓那笔 1:5（本身正期望，躺着都赚）
> - 小生意 = A、B 两个折扣区交易（顺手做的，为了多赚一点）
> - 顺手做 = 每笔都有亏的可能 → **所以要算这笔账：值不值得做这个"顺手"。**
> - **赚多亏少 → 值得试（闲着也是闲着）；亏多赚少 → 不值得（闲着不亏钱）。**

**先验证数学。数学成立，才拿到市场验证逻辑。数学不成立，根本不必去市场。**

## 1. 锁定的参数（理想化情形）

### 底仓（原始交易，1:5）
- 止损 = **20点**，止盈 = **100点** → 盈亏比 1:5
- 期望（单独算）= 50%×(+100) + 50%×(−20) = **+40点 = +2R**（1R=20点）

### 区域 A、B（副图几何定死）
- A、B 各 **50点** 区间，**同构**（理想化，为计算方便假定一致）
- 进场几何：第一点（底）= 0.705，第二点（进场参考）= 原始1:5的 50% 位置
- 手数 = **比例**，1 = 原始进场手数

### 区域内部各笔交易（Chairman 锁定，50点区间）
| 笔 | 触发 | 手数 | 盈亏比 | 赢 | 亏 |
|---|---|---|---|---|---|
| 50%入场 | 第一笔 | 1手 | 1:1 | +25点 | −25点 |
| 25%加仓 | 碰25% | 4手 | 1:3 | +37.5点 | −12.5点 |
| 回50%减仓 | 碰25%路径 | 减3手 | 必正(低买高平) | +12.5/手 | — |
| 回50%加仓 | 没碰25%路径 | 加3手 | 1:1 | +25点 | −25点 |

### 概率（Chairman 锁定）
- **所有分支概率 = 50%**
- **关键原则："50% 只能用一次，不能相乘，不能加减。"** ← 模型设计初衷

## 2. 决策树结构（37 种可能性 → 正确概率结构）

### 三层楼依赖（建筑逻辑）
- 1楼 = 原始交易（前提）→ 2楼 = 区域A → 3楼 = 区域B
- 下层塌 → 上层不建（时光不能倒流，时间轴确定）

### ⚠️ 概率结构的关键修正（今天最重要的一课）
**错误版（v1，已作废）：** 把"原始✓→A✓→B✓"当成三道独立50%生死关**连乘**（0.5×0.5×0.5），
大赢路径概率被压到 0.78% → 算出总期望 **−11.41点（假的）**。

**正确版（v2，Chairman 定）：**
- **原始交易 = 100% 前提**，不参与概率（认定方向成立才进场，不该有失败叶子）
- **A、B = 两笔各自独立结算的交易**，各只用一次 50%
- **盈亏相加，不连乘**（独立 → 期望线性可加，这是数学定理）
- "碰25% / 没碰25%" = **市场走法的选择（路径），不是输赢概率**，不削减概率

**为什么正确：** A、B 不是"要同时成功才算赢"的联合事件，而是"先后做的两笔生意，各算各的盈亏，最后求和"。这就是"50%只用一次"的数学含义。

## 3. 计算过程（每一步怎么来的）

### 3.1 单区域的盈亏（成功/失败各50%）

**成功时（50%），两种走法各占一半：**
- 碰25%成功 = 减3手落袋(3×12.5=+37.5) + 剩2手冲最高TP(2×50) = **+137.5点**
- 没碰25%成功 = 4手冲最高TP(4×50) = **+200.0点**
- 成功平均 = 0.5×137.5 + 0.5×200 = **+168.75点**

**失败时（50%），两种走法各占一半：**
- 碰25%失败 = 5手全损(1手×−25 + 4手×−12.5 = −75) = **−75.0点**
- 没碰25%失败 = 4手全损(4×−25) = **−100.0点**
- 失败平均 = 0.5×(−75) + 0.5×(−100) = **−87.5点**

**单区域期望：**
```
EV(区域) = 0.5 × (+168.75) + 0.5 × (−87.5) = +40.62点
```

### 3.2 模型总期望（A + B 独立相加）
```
多策略 = EV(A) + EV(B) = +40.62 + +40.62 = +81.25点
```

### 3.3 对比基准（单一1:5一笔）
```
单一1:5 = 0.5×(+100) + 0.5×(−20) = +40.00点
```

### 3.4 结论
```
多策略 +81.25点  vs  单一1:5 +40.00点
→ 多策略 ≈ 单一1:5 的 2 倍  ✅ 多策略更优
```

## 4. A、B 两笔独立交易的完整分布（4种组合，各25%）

| 组合 | 盈亏 | 概率 |
|---|---|---|
| A成功 + B成功 | +337.5点 | 25% |
| A成功 + B失败 | +81.2点 | 25% |
| A失败 + B成功 | +81.2点 | 25% |
| A失败 + B失败 | −175.0点 | 25% |

→ **75% 的情况盈利**，只有"两笔都失败"（25%）才亏。

## 5. 底仓的处理（Chairman 决定，必须看懂）

**决定：底仓不单独计算，只作标注。**

- 底仓严格讲应单独算 = +40点（50%×1:5）。
- **但担心重复计算**：A、B 剩余仓"冲最高TP"的路径，可能已经把底仓那1手的行程算进去了（共享同一个最高TP / Original STOP）。
- **不确定是否重叠 → 底仓不单独加**（保守、防夸大）。
- **结果：+81.25 是保守值。底仓的正贡献尚未计入 → 真实只会更好，不会更差。**
- 原则：**模型宁可低估，不可高估。**

## 6. 模型最硬的地方（"减少亏损"的数学兑现）

- 失败时平均亏 **−87.5点**，成功时赚 **+168.75点** → 赢面 ≈ 输面的 2 倍。
- **机理：** 折扣区的近止损（25%加仓离止损极近）压住了亏损侧；加仓放大了盈利侧。
- 这正是 Chairman 一直追求的"**用头寸管理减少亏损**" —— 不是减少亏的次数，是**减少每次亏的幅度、放大每次赚的幅度**。**数学证明它成立。**

## 7. 诚实标注（结论的边界）

⚠️ **理想化假设**（影响精确数字，不影响方向性结论）：
- "最高TP 每手 +50点"（设为一个区间高度）—— 需用副图精确几何校正。
- 失败时各走法的全损点数按上述构成估算。
- 现实中 Original STOP 会随大级别位移移动；不会在离TP很近又守原始低止损的位置进场。本模型为**理想化情形**，照图算。

⚠️ **胜率假设：** 全部 50%。若折扣区实战能把胜率提到 50% 以上（Chairman 理念暗示如此），优势更大；若低于50%，需重算。
