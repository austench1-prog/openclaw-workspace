## ES/NQ 背离判断（四种情形规则卡）⭐

**Chairman 原话（11:16 AM）：**
> 简单地讲，就是在目前它如果两者都突破了buy side，就算是有wick的突破也算，那么我认为行情会继续向上，寻找下一个目标。如果两者有一个就是强烈地向上，最终回落在收盘的时候回落到buy side以下，另外一个是没有向上，完全没有碰到，那么这种情形，我认为也是属于一种背离的情形。那么还有一种情形呢，就是说一种有一个在buy side这一边形成了一个Equal High，那么另外一个是没有碰到。这种情形也算是属于一种背离。但是如果一个是平了，另外一个是突破，那我认为呢，这个也不算。

**Dragon 结构化记录：**

4小时 ES / NQ Divergence（背离）判断

**情形1：不算背离 / 继续向上**
- ES 和 NQ 两者都突破 Buyside（即使只是 wick 突破也算）
- 判断：行情继续向上，寻找下一个目标位

**情形2：算背离**
- 其中一个：强烈向上冲 + 但收盘时回落到 Buyside 以下
- 另一个：完全没有向上，连 Buyside 都没有碰到
- → 属于背离

**情形3：算背离**
- 其中一个在 Buyside 附近形成 Equal High
- 另一个完全没有碰到 Buyside
- → 属于背离

**情形4：不算背离**
- 一个形成 Equal High
- 另一个直接突破 Buyside
- → 不算背离

**核心定义（Dragon 总结）：**
> 背离的重点不是"一强一弱"本身，而是两者在 Buyside 附近对流动性的处理方式明显不一致，并且这种不一致足够大。

## AP 策略两种用法（8:40 PM）⭐ 核心定义

**Chairman 原话：**
> AP的两种用法——一种是在以前形成的波段里面运用AP来寻找入场点，也就是说看他在哪些位置他有可能会延续找到一个合理的进场点或者转折，因为一种用法就是用AP的这个中文线来判断将来的一个点位它会到哪，就是预测他后面的点位，运用AP的终点或者说他的这几个关键的点位，基本上这次伯纳切的比较标准的用法。

**图：** `df18ff31-e56e-43d2-bc41-e1f211713d61.jpg`

**用法一 — 回顾型（寻找进场点）**
在已经形成的波段上画 AP，观察价格在哪些关键位置有反应：
- 找延续进场点（顺势）
- 找转折点（逆势）
- 用 0.705–0.79 和 0.295–0.41 这两个震荡区判断支撑/阻力

**用法二 — 预测型（判断未来点位）**
用 AP 的关键位来预测后续价格目标：
- 以当前波段的起点/终点为基准画 AP
- 用 0 / 0.295 / 0.41 / 0.5 / 0.705 / 0.79 / 1 这些位置预判价格下一步会到哪里
- 本质是标准 Fibonacci 的运用方式，只是级别是 AP 自定义的

**实际操作结合：**
- 用用法二定方向和目标
- 用用法一在已有波段里找精确进场点
- 两者配合确认信号

## 大小时间框架互换原理（11:47 PM）⭐ 核心理论

**Chairman 原话（节选）：**
> 我们不能单纯的说大时间决定小时间，其实，我们有的时候是用小的时间来去判断这个大时间框架。那么当有了这个时候，我们就会用这个4小时的这个最高点来作为一个可靠的可能的止损点。这就是说这个时间框架大小时间框架是互换的。

**图：** `37db1fe2-178b-46f4-8fd3-ec116ab61842.jpg`（NQ 4H+15m 双图，白色箭头标注）

**框架解析：**

**第一步 — 小判大（15m → 4H）：**
- 下行过程中 15m 十字星柱体出现 → 形成"可能的止损点"
- 有了这根线 → 判断 4H 没有超过此点 → 4H 可能正在形成阶段性高点
- 没有这根 15m 线 → 这个判断不存在（**小时间框架帮助识别大时间框架转折**）

**第二步 — 大给小（4H → 15m）：**
- 4H 最高点 → 作为可靠的止损参考
- 等 4H 这根柱完全收盘后 → 才可以去 15m 找进场点
- 原因：4H 未收盘前止损点不确定 → R:R 无法计算 → 不值得进场

**为什么等 4H 收盘：**
- 4H 收完后向上做止损（最高点）→ 盈亏比约 1:5
- 若用最上面那根 15m 的柱高做止损 → 盈亏比不够，不值得尝试

**ICT 时间概念：**
- 图上白色箭头的点 = 有效的交易时间节点（时间 + 价格都对齐才是交易机会）
- 这就是 ICT 强调的"交易时间"概念——只有打了白色箭头的位置，才有真正的交易点

**核心结论：**
> 大小时间框架的关系不是单向的"大决定小"，而是双向互推：
> - 小框架（15m）→ 识别大框架（4H）转折信号
> - 大框架（4H）→ 提供小框架（15m）的止损依据
> 两者在特定结构下角色互换，这是整个框架最重要的底层逻辑。

**Chairman 原话：**

引线的核心用法 = 预判回落方向：
- 看到长引线向上 → 预判价格有压力回落到引线区域

- 引线 ≠ 直接等于 Block（Block 是后续发展确认的结果）
