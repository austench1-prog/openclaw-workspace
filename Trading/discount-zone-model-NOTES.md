## 关于 Fractal（分型）的含义 — 模型边界定义

**核心：** 一个原始交易区域(original start → original TP)，可以由不同数量的内部交易来完成。
这就是**分型(Fractal)**的含义 —— 同一个大结构，内部可以是 1 个、2 个、N 个自相似的小交易区域。

### 大时间框架下，完成一个原始交易区域的几种情形：

1. **趋势交易（Trend）：** 里面没找到合适的内部交易，价格直接从 original start 一路走到 original TP 走完。
2. **暴力交易（Violent）：** 几根柱子就把整个区域走完。
3. **简单交易（Simple）：** 里面形成 1 个交易A，就把区域走完。
4. **N个区域：** 形成 A、B、C、D … N 个内部小交易区域，逐个完成。

### 今天分析的定位：
- 今天的模型 = **用两个小交易区间(A + B)来完成**一个原始交易区域 的情形。
- **掌握了"2个内部区域"这种情况 → 就可以对所有情形(1个/N个)做推广分析。**
- A 和 B 同构（理想化假设），B = A 的策略重演。

---

## 关于时间轴 — 推演的正确框架（Chairman 锁定）

- **时间轴是确定的、不可逆的**（时光不能倒流）。B 必然在 A 之后。
- A 交易区域关闭后 → 到新区域 B → 用同样策略重演。
- "B 是否承接 A 的仓 / 是否新进场" 这类问题在现实中无意义 —— 因为时光不能倒流，A 关了就是关了。
- **正确推演框架：先确定"时间的推演"（A→B 顺序固定不变）→ 再在确定的时间轴上，讨论"价格的不确定推演"。**
- 即：时间维度=确定，价格维度=不确定。两者分开，先锁时间再推价格。
