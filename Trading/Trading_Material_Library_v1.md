## 【策略建设原则】

1. 素材库中的内容不需要全部融合在一个策略里，按需选取
2. 可以从素材库中创建多个不同策略，应对不同产品、市场状态和交易目标
3. 策略分两类：
   - **市场因素策略**：进场逻辑、方向判断、止损止盈、时间框架配合
   - **非市场因素策略**：仓位管理、盈利目标、账号风控、多账号协调
4. 两类策略可共同使用，但分开思考，不混淆

## 【素材库管理铁律】（Chairman 2026-06-17 锁定）

**核心价值：** 这些素材是 Chairman **在状态中一眼抓住、一张一张手动抠下来的原始截图**。这种工作**人类做不出第二次**——错过那一瞬间、再回去想是不可能复现的。**原始性本身 = 真正的价值。**

**四条铁律（不可违反）：**
1. **即抓即存、原样保管。** Chairman 丢进来一张，Dragon 瞬间归档，不丢失。
2. **绝不修改原始素材（图 + Chairman 原话）。** 不 P 图、不裁剪、不重画。修改就没有意义。需要回测验证的东西回测里早就有；这里收集的是最原始的东西。
3. **不合并。** 只做**归类**（归到同一类目下、建交叉索引），**每条独立保留**。绝不揉成一条。
4. **不断丰富、不断加强。** 同一形态（如 Pin Bar / 十字星）在实战中每看到一根就原样收进对应类目 → 素材库越来越丰富。
5. **原子化原则（Chairman 2026-06-18 锁定）：** 素材以**最小化、最简化**为目标，拆到不能再拆。单独的素材在系统里可以互相作用、自由组合，但不预先揉成一个，因为不知道哪一次只需要其中几个的组合。**不要把可以分开的规则串成一条链。**

**素材的两条线（区分清楚）：**
- **规则（Rule）：** 如“看到这种线必先回补引线才可能上行”——抽象的判断逻辑。
- **零件 / 实例（Specimen）：** 同一个东西有没有**不同变体**（不同的 Pin Bar、各自怎么判）+ 实战中不断收集的原始图例。存于 `material_specimens/<类目>/`。

**实例归档格式（仅索引，不动原图）：** 日期 · 品种 · 时间框架 · 形态名 · Chairman 原话（逐字保留）· 图路径。

## 【AP Fibonacci 参数（GB 模型）】

| 级别 | 含义 |
|---|---|
| 1.0 | 锚定高点 |
| 0.79 | OTE 区域上边界 |
| 0.7475 | OTE 核心进场位 |
| 0.705 | OTE 区域下边界 |
| 0.5 | 中轴（红色，止损移动参考） |
| 0.41 | 核心回撤目标 |
| 0.295 | 极值镜像目标 |
| 0.0 | 锚定低点 |

**参数关系：**
- 0.295 = 0.7475 的极性镜像
- 0.41 = 0.705 的负一标准差衍生

**两种用法：**
- 回顾型：在已形成的波段上画 AP，寻找支撑/阻力和进场点
- 预测型：以当前波段为基准，预判后续价格目标

**两个震荡区间：**
- 上震荡区：0.295 ↔ 0.41（价格在此反复震荡，观察方向）
- 下震荡区：0.705 ↔ 0.79（价格在此找支撑或阻力）

**震荡 vs 趋势出场：**
- 震荡行情：在 0.7475 进场，0.41 或 0.295 止盈
- 趋势行情：目标直接刷新高点或低点

## 【市场结构（MSS）判定原则】

- 真正的结构转变必须看 **K 线实体收盘**（Body Close）
- 仅引线穿越不算突破，该区域仍然有效
- 引线 = 该区域依然在提供支撑或阻力

### 【三振反转原则】（Chairman 2026-06-17 锁定）

**一句话：** 在关键位确认反转，要看到 **≥3 次尝试突破都没成功**，才算比较确认。不根据一次尝试下结论。

> **2026-06-18 补充素材：** 震荡区间三振 + ABC双路径（见下方 →【震荡三振 ABC 双路径】）。两条原则同根，建议对照阅读。

- 期望：关键区出现 **3 次想突破但最终没成功** → 通常形成**三根连续的 / 结构型**的形态 = 较好的反转确认。
- **典型形态：** 努力尝试 3 次没成功，常表现为**三根比较长的影线**（每根长影线 = 一次试图突破但被打回）。
- **最不该做的：第一次尝试就下判断**——那时“认为突破”也不对、“认为反转”也不对。
- 强调：**看多次尝试（最好 >3 次），不是一次。**

**与体系衔接：** 与“Body Close 才算突破”同源（多次尝试失败 = 反向确认）；与【引线逻辑】多根原则一致（不要认为只有一根）；与“冲高勿追”互为表里。

### 【震荡区间内：突破 vs 回调 的判断方法】（Chairman 2026-06-17 锁定）

**原稿：** `austin_raw_archive/2026-06-17/_RAW.md` [10:05]；图 `1005_msg_breakout_vs_pullback_CHoCH_15m.jpg`。

**要解决的繠结（人最容易搞不清的）：** 在一个 Sellside–Buyside 构成的**震荡交易区间**里，价格到底是**突破了，还是要回调了**？这是交易中反复纠结的点。本方法给出一个判断口。

**术语对准（ICT）：** Chairman 口中的“Change Structure” = **CHoCH（Change of Character，性质转变）**。图上**叉 ✖ 和勾 ✔ 那两个点都是 CHoCH**（都是突破前一个 sweep point）。

**判断步骤（图上 NQ 15m）：**
1. 价格先**向上**走，突破前面一个 sweep point → 形成第一个 CHoCH（勾 ✔ ）。
2. 随后**回落**，向下突破“叉 ✖ ”那个前面的 sweep point → 第二个 CHoCH。
3. **判断从第二个突破（叉 ✖ 这个点被突破）才开始。**
4. 回落突破了叉✖点后，到下面却**没有**去突破那个**蓝色 OB++**，而是**形成了一个灰色 OB++**。
5. **判定：这个灰色 OB++ 会起作用，把价格推到 Buyside 之上。**（这就是判断的基础。）

**大环境辅助条件（必须一致）：**
- 上方有价格吸引力（Buyside 流动性）；下方有 1H 重要区域。始终的判断 = 价格需向上去到达最低目标位。
- 这些大环境只是**辅助**，但**必须与上面的结构判断一致**。
- **铁律：若大环境相反 → 即使这个结构判断成立，也不要做任何操作。**

**核心：** 聚焦用这两个 CHoCH（叉/勾）来判价格走势——是突破还是回调。下方是否突破原有 OB（蓝）还是另形成新 OB（灰）= 关键分水岭。

**🔴 补充（心理/素质，10:07 PDT）— 红色闪电区 = 成熟交易员的勇气：**
- 图 `1007_msg_red_lightning_courage_zone_15m.jpg`：红色闪电标在**灰色 OB++ 区**（即上述判断中会起作用、把价格推上 Buyside 的那个 OB）。
- **Chairman 原话：** “一个成熟的交易员就需要有勇气在这个红色闪电这一个区域来寻找向上做的交易机会，这才是一个成熟的交易员需要的素质。”
- **含义：** 判断成立后，进场点恰恰是价格正在下推、人最恐惧的那个区域（灰 OB++）。这里“向上做”需要勇气——与人本能相反。
- **与系统衔接：** 这正是“系统要解决人不敢操作”的场景（同 R006 白箭头痛点）。成熟交易员的“勇气” = 系统的“无情绪执行”。
- **打勾位 = “已向上突破”的定义（补充，10:26 PDT）：** 当箭头那根线**向下突破了叉✖位、并形成灰色 15m block** 之后 → 就判定**打勾✔那个位已经“向上突破”**了。**哪怕只突破了一点点，也算向上突破。**（这是对“两个 CHoCH 判断法”的明确化：打勾位的突破资格由后续叉✖被破+灰 OB 形成来追认。）
- **风控支撑（勇气的理性基础，10:10 PDT）：** Chairman 原话——“在这种位置，就算是失败，这个风险也是能承受的。”
  → 勇气不是蓮子。这个位置（灰 OB++ 边缘）止损近、R:R 好 → **即使错了，损失也在可承受范围内**。这才是勇气的理性基础（与【风控纪律】一贯：看到机会但不满足要求则不进，损的只是一个机会、不是钱；此处满足要求，即使败也只是可承受的小损）。
- **⭐ 升华（Chairman 纠正，10:30 PDT——更准确的表述）：** 为什么这个地方进场才是成熟交易员的表现——不是“勇气”那么简单，而是“**这是建立在超强的认知上面所做出来的决定和判断。**”
  → 勇气 ≠ 胆量大。真正的成熟 = **超强认知**（对结构/CHoCH/OB/大环境/R:R 的系统性认知）支撑下的决定与判断。“敢在人最恐惧处向上做”是认知的**结果**，不是性格的勇。
  → **与系统衔接（更准）：** 系统的价值不只是“无情绪”，更是把这种“超强认知”固化成可重复、可执行的规则 → 人的认知有状态波动，系统把峰值认知固定下来每次执行。

**⭐ 补充：为什么在这里入场——入场理由三问法（✅ 2026-06-18 正式入库）**

直接回答了「为什么在别人看来不可能的位置入场」这个问题。

**三问（至少一项「特别」就构成交易机会）：**
1. 盈亏比是否**特别好**？
2. 走势是否**特别明确**？
3. 止损是否**特别坚固**？

**关键字：「特别」。** 不是三项同时存在，而是其中至少一项达到「特别」的程度。

| 场景 | 判断 |
|---|---|
| 三项都平常 | 不是交易机会，不入场 |
| 只有一项特别好，其他一般 | ✅ 构成交易机会 |
| 三项同时特别好 | 极少发生，不必强求 |

**实战逻辑：** 当价格在别人看来不可能的位置，我们敏锐地发现其中一项「特别」——比如止损极近（特别坚固）或 R:R 极佳（特别好的盈亏比）——这就是我们眼前的交易机会。这就是「超强认知」的具体内容。

### 【关键位置的持续价值（突破后不失效）】（✅ 2026-06-18 正式入库）

**核心观点：**
对于**事先画好的关键横线**（如今日市场上下行分界线），当行情突破这个关键位置之后，这个位置并不就此失效。

**关键位置突破后的两种用法：**
1. **向下做时：** 把这个位置作为**止盈点**（从上方做空，以此关键位为平仓目标）
2. **向上做时：** 把这个位置作为**入场点**（价格回测此关键位时买入）

⚠️ **修正记录（Chairman 2026-06-18 09:17 纠正）：** 原文「向下做 = 止损」是错误理解。正确理解：前提是行情已向上突破这个点，所以向下做时入场在上方，这个位置是目标（止盈），不是止损。

**持续价值原则：**
- 不是“一次性看到它过去就没有事了”
- 这个关键位置**在当天交易中始终有价值**
- 验证方式：连续多根柱体在这个位置做出上述两种反应 → 证明关键位置判断正确且起作用

**实战示例（2026-06-18 NQ）：** 15m 图两个白色叉叉点 = 行情分别触及今日上下分界线，两次都做出与分界线相符的反应。

## 【引线（Wick）逻辑】

**基本特性：**
- 引线天然具有**吸引价格反向突破**的特性
- 引线被反向突破后 → 形成被确认的强 Block
- 每个判断都有时效，价格超过引线产生的区间后，判断结束

**长上引线（Pin Bar）完整逻辑：**
- 长上引线压下来之后，不期望直接一路向下
- 预期价格会先回来填补引线，或突破引线高点
- 然后才形成真正的走势方向
- 引线的高/低点 = 后续操作的目标价位

**4小时引线在15分钟的表现：**
- 4小时引线范围 = 15分钟进场点的有效区间
- 15分钟进场点必须在4小时引线范围内

**引线作为 Block：**
- 正向：引线区域支撑/阻力有效，价格倾向于不回头
- 反向穿越后离开：引线变成反向 Block，强力阻挡价格回归

### 引线的双重用法（sweep point → OB + 趋势线，2026-06-14 确认）

**核心：一根关键位置的引线出现，同时干两件事** —— 不是一个信号，是两个：
1. 找 Order Block（空间：在哪挂单）
2. 建趋势线（方向：趋势怎么走）

**第一重：引线 → 动态 Order Block（OB 随 sweep point 升级）**
- 引线一形成（图上 A 这根长引线）→ 关键位置先理解成一个 OB（黄色框）。
- 第二个 sweep point（B）形成 → 把原始 OB 调整成新 OB = **A、B 之间**的蓝色 OB（OB++）。
- OB 不是死的，随新 sweep point 不断重定义。
- 调整后 OB 两种走向：向下突破 OB++ → 交易区间被突破（走趋势）；在 OB++ 反弹 → 继续区间内看（震荡）。

**第二重：引线（sweep point）→ 趋势线（三点才成线）**
- 用不断移动的 sweep point 判断趋势（A→B→C→D→E→F）。
- ⚠️ **三点才成线**（硬规则）：只有两点时（如 A-B 红线）还不能叫趋势线；到 F 点（第三点到位）→ 红色趋势线成立。
- 黄色线严格讲还不算趋势线；白色线才算。白色线有两种画法（斜率不同）。

**区间关系（更新图补全）：** OB / sweep 在 **Sellside 区间下沿**形成；三条趋势线从底部 sweep 点扇形向上、穿越区间、指向 **Buyside**。

**分工：** OB 管“区间内”，趋势线管“突破后怎么走”。趋势线成立后 = 后面流动性的重要参考（$$$ 标在红线上 = 流动性/目标位）。

**与体系衔接：** “三点成线”= 防加戏的硬约束，与分析纪律一脉（两点不够就不提前下结论）；OB 随 sweep 动态升级 = 与 FVG 修正同源（给每个元素一个可解释规则）。

## 【FVG（Fair Value Gap）多时间框架用法】

- 在4小时 FVG 内寻找包含或重叠的15分钟 FVG
- 用15分钟 FVG 作为止盈的精确参考点
- 作用：把止盈从4小时大区间缩小到15分钟精确位置

**FVG 重叠的意义：**
- 15分钟 FVG 被4小时 FVG 包裹 → 强烈吸引价格回到该区域
- 通常作为止盈目标点

### Chairman FVG 用法（对 ICT 的修正版，2026-06-14 确认）

**立场：** 不照搬 ICT 公开 FVG 打法。ICT 公开版的硬伤 = 进场/止损/止盈三点都没有合理解释 → 胜率注定低。本用法反过来：**先锁风险，再倒推进场**。Chairman 不常用 FVG 进场；若用，必须按以下三要素。

**1. 止损（最关键，先定）**
- 放在**同级别前一根柱体的最高/最低点**。
- ❌ 绝不能用 FVG 本身的任何一条边做止损 —— 用 FVG 边做止损胜率极低。
- 止损拉太远 = 失去用 FVG 进场的意义。

**2. 进场点（由盈亏比倒推，不是先定）**
- 顺序：先定止损 → 看到止盈 → 算出盈亏比 → 在这个盈亏比内找一个合理进场点。
- **必要条件：盈亏比内找得到合理进场点，才入场；找不到，就不入场。**
- 与体系一致：风险先行，机会服从风险。

**3. 止盈（用 FVG 本身 —— 这才是 FVG 真正的价值）**
- 理念：有价值的 FVG 会引导价格去填补它 → FVG 当**止盈**比当止损合理得多。
- **第一止盈位 = FVG 最近的那条边**。
- 到这条边：**坚决止盈**。不要期望它在这里回调、不要有过多期望 → 唯一合理操作就是止盈。

**逻辑闭环：** FVG 本质是“价格要去填的缺口” → 它是目标（止盈/磁铁），不是起点（进场/扳机）。止损交给“前柱极值”这种结构性可解释的点 —— 解决了 ICT 三点无解释的硬伤。

**与体系衔接：** 吻合进场7条（明确止损/止盈/盈亏比）；也呼应分析纪律（到边就走，不加“会不会回调”的戏）。

### 【MFVG 定义】（Chairman 2026-06-17 锁定）

**定义（我们采用的）：** **MFVG = price action 中 Demand/Supply 交换（交互）的区域。**

**别人的叫法（仅作背景，不采用）：** ICT 一些人叫它 **IFVG / Inverse FVG（反向 FVG），也叫 Vivo FVG**——本是一个向下 FVG，经价格走势后又形成向上 FVG，两个反向 FVG 重合的区域。我们**不用这套复杂解释**。

**方法论（Chairman，重要）：**
- 不把概念解释得过于详细——这是很多技术分析的毛病。**概念永远只是概念，价格想穿就穿、想变就变。** 在定义名词上花太多时间没意义。
- 但**始终要给它一个“你我都能理解的概念”，而不完全是一个名词。**

**与 FVG 的区别（体系内）：** 普通 FVG = 价格要去填的缺口（磁铁/目标）；MFVG = Demand/Supply 交换区（攻防转换的位置）。推演中 MFVG 常被用作分水岭/可作 STOP 的点（见震荡区间突破 vs 回调、R005/R007 推演）。

### 【被完全包裹的十字星（孕线十字星）= 新一段行情的起点】（✅ 2026-06-18 正式入库）

### 【反直觉 K 线走势：回调柱能否触到前一根开盘价】（✅ 2026-06-18 正式入库）

**核心逻辑：**当一根方向性柱体出现后，反向回调柱能否触到前一根柱体的开盘价，判断结果反直觉。

**三种场景对比：**

| 场景 | 回调柱特征 | 常规判断 | 实际结果 | 反直觉点 |
|---|---|---|---|---|
| **组一（1–4号）** | 2号回调未祸到1号开盘价，但**超过中点** | 回调弱，应继续下行 | ✅ 3、4号继续上升 | 看起来弱却有动力 |
| **组二（5–7号）** | 6号回调祸到5号开盘价（甚至曾突破前高），最终**收在开盘价** | 回调强，应继续上行 | ❌ 7号立即下行突破一切 | 看起来强却立即反转 |
| **组三（8–10号）** | 8号回调未祸到7号开盘价 | 回调弱 | ✅ 9【10号继续上升 | 同组一模式 |

**关键判断规则：**
- ✅ **回调未祸到开盘价 + 超过中点** → 趋势续航（看起来弱，实际有动力）
- ❌ **回调收盘刚好落在前一根开盘价（两价相平）** → 转折信号增强（看起来强，实际反转）

### 【关键位置平仓后再入场三条件】（✅ 2026-06-18 正式入库）

**平仓后，先看大趋势有没有改变。** 若要再入场，必须同时满足以下三条：

| 条件 | 要求 | 目的 |
|---|---|---|
| **条件1** | 至少完成一根**同级别 K 线**（这根必须走完） | 避免在混乱区间仓促再入 |
| **条件2** | 在**小一个级别**的 K 线上已形成**明确的止损点** | 确保止损有结构依据 |
| **条件3** | 在新止损点上能找到合理的 **1:5 入场结构** | 确保盈亏比值得再入 |

**三条不齐 → 不入场。**

**设计意图（两步兼顾）：**
- 第一步：到关键位立即平仓 → **锁住盈利**
- 第二步：三条件齐 → **安全方式继续后续行情的盈利**
- 本质：把「资金管理」这个难题分成两步，在锁利和续盈之间取得平衡

## 【策略使用纪律：每笔交易只用一个策略】（✅ 2026-06-18 正式入库）

**核心规则（同一时间框架内）：**
每天可以用多个策略，但**每笔交易只用一个策略**。

**执行铁律：**
- 市场给出入场机会 → 确认是哪个策略触发 → 用该策略定止损/止盈 → **锁定，不改变**
- 即使其他策略的视角给出不同点位 → **无视，等当前策略执行完成**
- 完成后（无论盈亏）→ 再看下一个机会是哪个策略 → 切换到那个策略

**滚动逻辑：**
```
策略A触发 → 用A执行完 → 看到策略B机会 → 用B执行完 → 看到策略A机会 → 用A执行...
```
每笔交易独立。不把多个策略揉进同一笔。

**为什么：**
用不同策略同时看同一行情 → 止损/止盈互相矛盾 → 市场一动就产生拉扯 → 最终无所适从。

**大逻辑：** 不断用一个策略找到1:5盈亏比的交易，**滚动式**做交易。


**⚠️ 重要例外（跨时间框架不受此限）：**
- 本规则只适用于**同一时间框架内**
- 大小时间框架之间是「策略 + 工具」的关系，互不干扰（见【大小时间框架双向互推】）
- 示例：4H 用策略A → 15m 内用ABCD找进场点 → **不冲突**，因为层级不同

### 案例（NQ 做空，4H + 15min 双图推导）

**第①步 — 用 15min 判断 4H（小推大）：**

- 判断 4H 是阶段性高点后 → 用 **4H 那根 K 线的最高点**（~29,306）作为可靠止损。

**第③步 — 入场/止盈/盈亏比：**
- 入场 = **4H 那根 K 线的收盘价**（~29,140）
- 止损 = **4H 最高点**（~29,306）
- 止盈 = **4H 开盘价**（~28,625，理想目标）
- 15min 上量出：**盈亏比 ≈ 1:5** ✅

**为什么必须等 4H 那根 K 线收完才入场（关键）：**
- 这是**盈亏比**的问题。等 4H 收完 → 才能用 4H 最高点当止损 → 止损被压缩 → 盈亏比才到 1:5。
- 若 4H 未收（止损点不存在），只能用上面那个 15min 止损点 → 止损太远 → **盈亏比不值得做**。
- 结论：这笔不赌高胜率，**赌的是盈亏比（1:5，胜率不高也值得）**。

**时间概念（ICT）：** 唯有白色箭头那个点 = **20:00** 才是可能的交易时间点；市场也正好在这个时间给了机会 → 时间 + 结构 双重 confluence。

**方法论价值：** 这是第一个“全链条走通”的真实案例 —— 必要条件（4H 方向/时间）+ 双向互推（小判大、大给小）+ 结构性止损 + 盈亏比驱动（1:5）+ ICT 时间窗（20:00）的协同。

### 时间框架一致性的真正含义（2026-06-14）

**反直觉核心：“完全一致”反而是最差的进场点。不是各级同向才好。**

**理想对齐（最好、最合理）：**
- 4H 上涨 → 15min 还在**下跌（回调）中** → 但**比 15min 更小的框架（1min 或 5min）已经确认了 15min 的反转**。
- （注：推动 15min 反转的一定是更小的框架，不是 1H—1H 比 15min 大。）
- 即：大方向确定 + 小框架还在逆向回调 + 最小框架（1/5min）刚刚转身 → **最佳进场**。

**最差的“一致”（趋势已成，但不能进）：**
- 4H 向上、15min 也完全走出向上、1min 也完全向上。
- 趋势确实形成（没错），但：**盈亏比已经坏了**（价格已走一大段）+ **止损点难以确定**。
- 结论：**完全一致 = 你已经迟到了。**

**交易区间 vs 方向（关键）：**
- 4H 交易区间 ≠ 4H 必须有固定方向。我们确定的是一个 **4H 时间框架的交易区间**。
- **4H 的方向不是预设的，是根据小时间级别判断出来的**（可能向上/向下）—— 即上文“小判大”。区间是舞台，方向是小框架推导出的剧情。

**区间内只做一致方向（战术自由）：**
- 4H 交易区间内，交易策略可以**只做与（判断出的）方向一致的单**。
- 15min 向下回测的那一段 → **可以不交易**，等更小框架（1min 或 5min）带出反转趋势后再交易。
- ⚠️ 但**不是必须等 15min 完全走出与 4H 一致的趋势才交易**—— 那就迟到了（回到第一点）。

**一句总结：** 方向一致指“大方向确定 + 最小框架刚反转”的早期对齐，不是“所有框架都同向”的晚期趋势。区间固定，方向靠小框架推导，区间内只做一致方向 —— 但要在反转初期进，不等完全走出。
