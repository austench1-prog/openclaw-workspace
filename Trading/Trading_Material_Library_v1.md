## 【策略建设原则】

1. 素材库中的内容不需要全部融合在一个策略里，按需选取
2. 可以从素材库中创建多个不同策略，应对不同产品、市场状态和交易目标
3. 策略分两类：
   - **市场因素策略**：进场逻辑、方向判断、止损止盈、时间框架配合
   - **非市场因素策略**：仓位管理、盈利目标、账号风控、多账号协调
4. 两类策略可共同使用，但分开思考，不混淆

## 【时间框架结构】

**组合A（主要）：**
1分钟 → 15分钟 → 4小时 → 周线

**组合B（备用）：**
5分钟 → 1小时 → 日线 → 月线

规则：每级之间隔开一个时间段，不跳级使用

**框架职责：**
- 大框架（4小时/周线）：判断趋势方向、锚定关键区间
- 中框架（15分钟）：确认进场区域，必须在4小时引线范围内
- 进场框架（1分钟/5分钟）：寻找精确进场点位

## 【AP Fibonacci 参数（GB 模型）】

| 级别 | 含义 |
|---|---|
| 1.0 | 锚定高点 |
| 0.79 | OTE 区域上边界 |
| 0.7475 | OTE 核心进场位 |
| 0.705 | OTE 区域下边界 |
| 0.5 | 中轴（红色，止损移动参考） |
| 0.41 | 核心回撤目标 |
| 0.295 | 极值镜像目标 |
| 0.0 | 锚定低点 |

**参数关系：**
- 0.295 = 0.7475 的极性镜像
- 0.41 = 0.705 的负一标准差衍生

**两种用法：**
- 回顾型：在已形成的波段上画 AP，寻找支撑/阻力和进场点
- 预测型：以当前波段为基准，预判后续价格目标

**两个震荡区间：**
- 上震荡区：0.295 ↔ 0.41（价格在此反复震荡，观察方向）
- 下震荡区：0.705 ↔ 0.79（价格在此找支撑或阻力）

**震荡 vs 趋势出场：**
- 震荡行情：在 0.7475 进场，0.41 或 0.295 止盈
- 趋势行情：目标直接刷新高点或低点

## 【市场结构（MSS）判定原则】

- 真正的结构转变必须看 **K 线实体收盘**（Body Close）
- 仅引线穿越不算突破，该区域仍然有效
- 引线 = 该区域依然在提供支撑或阻力

---

## 【引线（Wick）逻辑】

**基本特性：**
- 引线天然具有**吸引价格反向突破**的特性
- 引线被反向突破后 → 形成被确认的强 Block
- 每个判断都有时效，价格超过引线产生的区间后，判断结束

**长上引线（Pin Bar）完整逻辑：**
- 长上引线压下来之后，不期望直接一路向下
- 预期价格会先回来填补引线，或突破引线高点
- 然后才形成真正的走势方向
- 引线的高/低点 = 后续操作的目标价位

**4小时引线在15分钟的表现：**
- 4小时引线范围 = 15分钟进场点的有效区间
- 15分钟进场点必须在4小时引线范围内

**引线作为 Block：**
- 正向：引线区域支撑/阻力有效，价格倾向于不回头
- 反向穿越后离开：引线变成反向 Block，强力阻挡价格回归

---

## 【FVG（Fair Value Gap）多时间框架用法】

- 在4小时 FVG 内寻找包含或重叠的15分钟 FVG
- 用15分钟 FVG 作为止盈的精确参考点
- 作用：把止盈从4小时大区间缩小到15分钟精确位置

**FVG 重叠的意义：**
- 15分钟 FVG 被4小时 FVG 包裹 → 强烈吸引价格回到该区域
- 通常作为止盈目标点

---

## 【Order Block（OB）逻辑】

**形成条件：**
- 引线是形成 OB 的核心元素
- 被反向突破后又回来 → 形成强力 Block

**判断方向：**
- 突破后无法回到原区域 → 反向 Block（强阻力）
- 被突破后价格在 Block 区间内震荡 → 方向未定，等待

**多时间框架 OB 配合：**
- 小时间框架 OB 被大时间框架 OB 包裹 → 小 OB 确认大 OB 有效性
- 两个时间框架方向一致 → 信号可靠性大幅提升

---

## 【蜡烛形态】

**强趋势确立形态：**
- 2–3根无方向蜡烛（十字星/小实体）+ 后续一根大方向蜡烛
- 这种形态的区域在未来价格回来时是强力阻力
- 反向突破难度大，需要同等强度的力量

**特殊蜡烛：**
- 极短实体 + 极长引线的十字形蜡烛
- 这种蜡烛形成后，无论后续走向，价格必须向下（或向上）穿过这条线
- 不可能直接跳过，必须先回来穿越

**三手指下降确认：**
- 反弹高点依次降低（第1>第2>第3）
- 每次降低 = 再次确认下降趋势

**ABC 组合：**
- A：顶部/底部反转形态
- B：两根蜡烛确认继续
- C：同类结构再次确认
- 当价格将来回到 B 和 C 位置时 → 重要转折参考点

## 【进场条件】

**进场必须满足：**
1. 15分钟进场点在4小时引线范围内
2. AP Fib 关键位置（0.705–0.79 或 0.295–0.41）
3. 从入场点到盈利目标有100 points 以上空间
4. 有明确的止损点
5. 有明确的盈利点
6. 盈亏比 1:5
7. 50% 位置必须是明显能够到达的（中间无明显阻力）

**动态止损规则：**
- 价格到达50%目标时，止损移动到50%位置锁利

---

## 【风控纪律】

**止损规则：**
- 下单后止损位固定不变
- 中途不追价、不扩大止损
- 亏了就认，不改单

**亏损冷静期（递进制）：**
- 第1次亏损 → 等至少15分钟
- 第2次亏损 → 等至少1小时
- 第3次亏损 → 等至少4小时
- 每天最多亏3次，第3次亏完当天停止交易

## 【辅助指标】

**TH/TL Daily Range（TNTL）：**
- 用途：判断当天行情看涨还是看跌，日线级别方向参考
- 公式（GC版）：P=(H+L+C)/3，B=2P+O-C，TH=B-L，TL=B-H
- 显示窗口：GC 18:00–13:30 ET

**ICT KillZone 指标：**
- 白线：True Day Open（Midnight 00:00）
- 红线：16:00 ET 收盘
- 蓝色框：亚洲盘区间
- 用途：判断当天方向的基准参考

**200日 SMA：**
- 在方向判断一致的前提下作为止盈/止损参考
- 各时间框架（1min/5min/15min/1h/4h）各有独立 200 SMA
- 多时间框架排列方向作为趋势确认参考

## 【分析纪律】

**核心原则（2026-06-14 Chairman 确立）：**
> 分析只对市场已给出的确定信息下结论，不主动往里加结构。信息不足时，结论就该简单。

- 市场只给几个确定信息，就只下几个结论。
- 不把上一个交易区间的复杂结构硬套到当前行情 = 自己加戏。
- 过度分析 = 制造不存在的确定性 → 导致在没 setup 时手痒。
- 与 less-is-more / “规则 > 逻辑” 同源：等市场给信息，不替市场编信息。

**应用示例（趋势二元判据）：** 跳空后，一个红框 + 一条线即可判趋势性质 —— 不回踩红框 = 确认趋势；回踩红框 = 降级为待观察趋势。不需要更多。
