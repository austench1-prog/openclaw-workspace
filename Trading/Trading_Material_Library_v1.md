4. 两类策略可共同使用，但分开思考，不混淆

## 【AP Fibonacci 参数（GB 模型）】

| 级别 | 含义 |
|---|---|
| 1.0 | 锚定高点 |
| 0.79 | OTE 区域上边界 |
| 0.7475 | OTE 核心进场位 |
| 0.705 | OTE 区域下边界 |
| 0.5 | 中轴（红色，止损移动参考） |
| 0.41 | 核心回撤目标 |
| 0.295 | 极值镜像目标 |
| 0.0 | 锚定低点 |

**参数关系：**
- 0.295 = 0.7475 的极性镜像
- 0.41 = 0.705 的负一标准差衍生

**两种用法：**
- 回顾型：在已形成的波段上画 AP，寻找支撑/阻力和进场点
- 预测型：以当前波段为基准，预判后续价格目标

**两个震荡区间：**
- 上震荡区：0.295 ↔ 0.41（价格在此反复震荡，观察方向）
- 下震荡区：0.705 ↔ 0.79（价格在此找支撑或阻力）

**震荡 vs 趋势出场：**
- 震荡行情：在 0.7475 进场，0.41 或 0.295 止盈
- 趋势行情：目标直接刷新高点或低点

## 【引线（Wick）逻辑】

**基本特性：**
- 引线天然具有**吸引价格反向突破**的特性
- 引线被反向突破后 → 形成被确认的强 Block
- 每个判断都有时效，价格超过引线产生的区间后，判断结束

**长上引线（Pin Bar）完整逻辑：**
- 长上引线压下来之后，不期望直接一路向下
- 预期价格会先回来填补引线，或突破引线高点
- 然后才形成真正的走势方向
- 引线的高/低点 = 后续操作的目标价位

**4小时引线在15分钟的表现：**
- 4小时引线范围 = 15分钟进场点的有效区间
- 15分钟进场点必须在4小时引线范围内

**引线作为 Block：**
- 正向：引线区域支撑/阻力有效，价格倾向于不回头
- 反向穿越后离开：引线变成反向 Block，强力阻挡价格回归

### 引线的双重用法（sweep point → OB + 趋势线，2026-06-14 确认）

**核心：一根关键位置的引线出现，同时干两件事** —— 不是一个信号，是两个：
1. 找 Order Block（空间：在哪挂单）
2. 建趋势线（方向：趋势怎么走）

**第一重：引线 → 动态 Order Block（OB 随 sweep point 升级）**
- 引线一形成（图上 A 这根长引线）→ 关键位置先理解成一个 OB（黄色框）。
- 第二个 sweep point（B）形成 → 把原始 OB 调整成新 OB = **A、B 之间**的蓝色 OB（OB++）。
- OB 不是死的，随新 sweep point 不断重定义。
- 调整后 OB 两种走向：向下突破 OB++ → 交易区间被突破（走趋势）；在 OB++ 反弹 → 继续区间内看（震荡）。

**第二重：引线（sweep point）→ 趋势线（三点才成线）**
- 用不断移动的 sweep point 判断趋势（A→B→C→D→E→F）。
- ⚠️ **三点才成线**（硬规则）：只有两点时（如 A-B 红线）还不能叫趋势线；到 F 点（第三点到位）→ 红色趋势线成立。
- 黄色线严格讲还不算趋势线；白色线才算。白色线有两种画法（斜率不同）。

**区间关系（更新图补全）：** OB / sweep 在 **Sellside 区间下沿**形成；三条趋势线从底部 sweep 点扇形向上、穿越区间、指向 **Buyside**。

**分工：** OB 管“区间内”，趋势线管“突破后怎么走”。趋势线成立后 = 后面流动性的重要参考（$$$ 标在红线上 = 流动性/目标位）。

**与体系衔接：** “三点成线”= 防加戏的硬约束，与分析纪律一脉（两点不够就不提前下结论）；OB 随 sweep 动态升级 = 与 FVG 修正同源（给每个元素一个可解释规则）。

## 【FVG（Fair Value Gap）多时间框架用法】

- 在4小时 FVG 内寻找包含或重叠的15分钟 FVG
- 用15分钟 FVG 作为止盈的精确参考点
- 作用：把止盈从4小时大区间缩小到15分钟精确位置

**FVG 重叠的意义：**
- 15分钟 FVG 被4小时 FVG 包裹 → 强烈吸引价格回到该区域
- 通常作为止盈目标点

### Chairman FVG 用法（对 ICT 的修正版，2026-06-14 确认）

**立场：** 不照搬 ICT 公开 FVG 打法。ICT 公开版的硬伤 = 进场/止损/止盈三点都没有合理解释 → 胜率注定低。本用法反过来：**先锁风险，再倒推进场**。Chairman 不常用 FVG 进场；若用，必须按以下三要素。

**1. 止损（最关键，先定）**
- 放在**同级别前一根柱体的最高/最低点**。
- ❌ 绝不能用 FVG 本身的任何一条边做止损 —— 用 FVG 边做止损胜率极低。
- 止损拉太远 = 失去用 FVG 进场的意义。

**2. 进场点（由盈亏比倒推，不是先定）**
- 顺序：先定止损 → 看到止盈 → 算出盈亏比 → 在这个盈亏比内找一个合理进场点。
- **必要条件：盈亏比内找得到合理进场点，才入场；找不到，就不入场。**
- 与体系一致：风险先行，机会服从风险。

**3. 止盈（用 FVG 本身 —— 这才是 FVG 真正的价值）**
- 理念：有价值的 FVG 会引导价格去填补它 → FVG 当**止盈**比当止损合理得多。
- **第一止盈位 = FVG 最近的那条边**。
- 到这条边：**坚决止盈**。不要期望它在这里回调、不要有过多期望 → 唯一合理操作就是止盈。

**逻辑闭环：** FVG 本质是“价格要去填的缺口” → 它是目标（止盈/磁铁），不是起点（进场/扳机）。止损交给“前柱极值”这种结构性可解释的点 —— 解决了 ICT 三点无解释的硬伤。

**与体系衔接：** 吻合进场7条（明确止损/止盈/盈亏比）；也呼应分析纪律（到边就走，不加“会不会回调”的戏）。

## 【Order Block（OB）逻辑】

**形成条件：**
- 引线是形成 OB 的核心元素
- 被反向突破后又回来 → 形成强力 Block

**判断方向：**
- 突破后无法回到原区域 → 反向 Block（强阻力）
- 被突破后价格在 Block 区间内震荡 → 方向未定，等待

**多时间框架 OB 配合：**
- 小时间框架 OB 被大时间框架 OB 包裹 → 小 OB 确认大 OB 有效性
- 两个时间框架方向一致 → 信号可靠性大幅提升

## 【蜡烛形态】

**强趋势确立形态：**
- 2–3根无方向蜡烛（十字星/小实体）+ 后续一根大方向蜡烛
- 这种形态的区域在未来价格回来时是强力阻力
- 反向突破难度大，需要同等强度的力量

**特殊蜡烛：**
- 极短实体 + 极长引线的十字形蜡烛
- 这种蜡烛形成后，无论后续走向，价格必须向下（或向上）穿过这条线
- 不可能直接跳过，必须先回来穿越

**三手指下降确认：**
- 反弹高点依次降低（第1>第2>第3）
- 每次降低 = 再次确认下降趋势

**ABC 组合：**
- A：顶部/底部反转形态
- B：两根蜡烛确认继续
- C：同类结构再次确认
- 当价格将来回到 B 和 C 位置时 → 重要转折参考点

**进场必须满足：**
1. 15分钟进场点在4小时引线范围内
2. AP Fib 关键位置（0.705–0.79 或 0.295–0.41）

- 价格到达50%目标时，止损移动到50%位置锁利

## 【风控纪律】

**止损规则：**
- 下单后止损位固定不变
- 中途不追价、不扩大止损
- 亏了就认，不改单

**亏损冷静期（递进制）：**
- 第1次亏损 → 等至少15分钟
- 第2次亏损 → 等至少1小时
- 第3次亏损 → 等至少4小时
- 每天最多亏3次，第3次亏完当天停止交易

## 【分析纪律】

**核心原则（2026-06-14 Chairman 确立）：**
> 分析只对市场已给出的确定信息下结论，不主动往里加结构。信息不足时，结论就该简单。

- 市场只给几个确定信息，就只下几个结论。
- 不把上一个交易区间的复杂结构硬套到当前行情 = 自己加戏。
- 过度分析 = 制造不存在的确定性 → 导致在没 setup 时手痒。
- 与 less-is-more / “规则 > 逻辑” 同源：等市场给信息，不替市场编信息。

**应用示例（趋势二元判据）：** 跳空后，一个红框 + 一条线即可判趋势性质 —— 不回踩红框 = 确认趋势；回踩红框 = 降级为待观察趋势。不需要更多。

## 【大小时间框架双向互推（核心机制，2026-06-14 案例确认）】

**核心突破：不是“大决定小”单向，是双向互推。有时用小时间框架去判断大时间框架。**

### 案例（NQ 做空，4H + 15min 双图推导）

**第①步 — 用 15min 判断 4H（小推大）：**
- 下行途中，15min 形成一根**十字星**，留下一个可观的止损点（~29,306）。
- 因为这个 15min 止损点存在 → 4H 后续没有超过它 → 判断：这个 4H 大概率不再创新高（阶段性高点）。
- **关键：没有这个 15min 止损点，“4H 是高点”的判断就不成立。**

**第②步 — 用 4H 当 15min 的止损（大给小）：**
- 判断 4H 是阶段性高点后 → 用 **4H 那根 K 线的最高点**（~29,306）作为可靠止损。

**第③步 — 入场/止盈/盈亏比：**
- 入场 = **4H 那根 K 线的收盘价**（~29,140）
- 止损 = **4H 最高点**（~29,306）
- 止盈 = **4H 开盘价**（~28,625，理想目标）
- 15min 上量出：**盈亏比 ≈ 1:5** ✅

**为什么必须等 4H 那根 K 线收完才入场（关键）：**
- 这是**盈亏比**的问题。等 4H 收完 → 才能用 4H 最高点当止损 → 止损被压缩 → 盈亏比才到 1:5。
- 若 4H 未收（止损点不存在），只能用上面那个 15min 止损点 → 止损太远 → **盈亏比不值得做**。
- 结论：这笔不赌高胜率，**赌的是盈亏比（1:5，胜率不高也值得）**。

**时间概念（ICT）：** 唯有白色箭头那个点 = **20:00** 才是可能的交易时间点；市场也正好在这个时间给了机会 → 时间 + 结构 双重 confluence。

**方法论价值：** 这是第一个“全链条走通”的真实案例 —— 必要条件（4H 方向/时间）+ 双向互推（小判大、大给小）+ 结构性止损 + 盈亏比驱动（1:5）+ ICT 时间窗（20:00）的协同。

### 时间框架一致性的真正含义（2026-06-14）

**反直觉核心：“完全一致”反而是最差的进场点。不是各级同向才好。**

**理想对齐（最好、最合理）：**
- 4H 上涨 → 15min 还在**下跌（回调）中** → 但**比 15min 更小的框架（1min 或 5min）已经确认了 15min 的反转**。
- （注：推动 15min 反转的一定是更小的框架，不是 1H—1H 比 15min 大。）
- 即：大方向确定 + 小框架还在逆向回调 + 最小框架（1/5min）刚刚转身 → **最佳进场**。

**最差的“一致”（趋势已成，但不能进）：**
- 4H 向上、15min 也完全走出向上、1min 也完全向上。
- 趋势确实形成（没错），但：**盈亏比已经坏了**（价格已走一大段）+ **止损点难以确定**。
- 结论：**完全一致 = 你已经迟到了。**

**交易区间 vs 方向（关键）：**
- 4H 交易区间 ≠ 4H 必须有固定方向。我们确定的是一个 **4H 时间框架的交易区间**。
- **4H 的方向不是预设的，是根据小时间级别判断出来的**（可能向上/向下）—— 即上文“小判大”。区间是舞台，方向是小框架推导出的剧情。

**区间内只做一致方向（战术自由）：**
- 4H 交易区间内，交易策略可以**只做与（判断出的）方向一致的单**。
- 15min 向下回测的那一段 → **可以不交易**，等更小框架（1min 或 5min）带出反转趋势后再交易。
- ⚠️ 但**不是必须等 15min 完全走出与 4H 一致的趋势才交易**—— 那就迟到了（回到第一点）。

**一句总结：** 方向一致指“大方向确定 + 最小框架刚反转”的早期对齐，不是“所有框架都同向”的晚期趋势。区间固定，方向靠小框架推导，区间内只做一致方向 —— 但要在反转初期进，不等完全走出。
