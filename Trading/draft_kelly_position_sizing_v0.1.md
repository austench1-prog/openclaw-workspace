## 一、结论先行
- 全凯利数学最优,但对胜率/盈亏比估计误差极度敏感 → 实盘禁用。
- 专业做法用 **分数凯利(1/4 ~ 1/2)**。建议起步:**1/4 凯利**。
- 凯利负责"相对大小与方向",**账户合规帽负责"不爆仓"** —— 两者叠加。

---

## 二、公式(套本体系参数)
- 盈亏比 b = 5(体系 1:5 硬门槛)
- 胜率 p = ___(待 Chairman 填:SIM/实盘真实胜率)
- 亏率 q = 1 − p

```
f* = (b·p − q) / b  =  p − (1−p)/b  =  p − (1−p)/5
```
f* = 单笔风险占账户的理论最优比例(全凯利)。

## 四、合规硬帽(凯利之上的天花板,不可突破)
```
单笔实际风险 = min( 分数凯利建议 , 账户单笔硬帽 )
```
- Apex $50k:Max DD $2,000 → 建议单笔硬帽 ≤ 账户 1% ($500),留 ~4 笔容错。
- TakeProfitPro $50k:Max DD $2,000(同上,待最终确认硬帽)。
- 仍受 Line 1:强制止损、16:09 ET FLATTEN、Max contracts(Apex=6)。

**示例:** $50k 账户、胜率30%、1/4凯利 → 凯利建议 4%=$2,000;
合规帽 1%=$500 → 取小 → **实际单笔风险 $500**。
