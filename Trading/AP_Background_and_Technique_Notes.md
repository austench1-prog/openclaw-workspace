## 一、AP 个人背景

- 交易起点：2019年底/2020年初，最早接触狗狗币，后转向期货市场
- 早期使用零售技术（9/18 EMA 交叉），在疫情后反弹行情中表现好，震荡行情中受挫
- 深入研究 ICT 后形成自己的体系，自定义为**独立思考的交易者**，不是纯 ICT 派
- 核心观点：价格具有**分形特性**——模型在5秒图有效，在1分钟、5分钟图同样有效

## 二、AP 斐波那契核心参数（GB 模型）

使用率：90%–95%

| 级别 | 含义 |
|---|---|
| 1.0 | 锚定高点（保护性高点） |
| 0.79 | OTE 区域上边界 |
| 0.7475 | OTE 核心级别，主要盲挂进场位 |
| 0.705 | OTE 区域下边界 |
| 0.5 | 中轴 |
| 0.41 | 核心回撤目标，0.705 向下一个标准差衍生 |
| 0.295 | 极值镜像目标，0.7475 的极性镜像 |
| 0.0 | 锚定低点 |

**参数关系：**
- 0.295 = 0.7475 在相对标度上的极性镜像
- 0.41 = 0.705 的负一标准差衍生
- 0.41 和 0.295 构成**震荡行情下的作弊码止盈区**

## 三、市场结构转变（MSS）判定原则

- 真正的结构转变（Flip/MSS）必须看 **K 线实体收盘**（Body Close）
- 仅引线穿越不算突破，该区域仍然有效
- 引线 = 该区域依然在提供支撑或阻力

---

## 四、两种市场环境下的出场策略

**震荡/巩固市场：**
- 进场：0.7475 级别
- 止盈：0.41 或 0.295
- 原因：避开随后的失败秋千（Failure Swing）和反转

**趋势/扩张市场：**
- 进场：OTE 级别回撤
- 目标：直接刷新高点或低点，不在 0.41 止盈

---

## 五、GB 水洼模型（Puddle / "Yeet"）进场逻辑

**多重共流（Confluence）要素：**
1. GB 级别（0.7475/0.295）
2. 订单块（Order Block）
3. 不平衡区（Imbalance/FVG）
4. 分形引线（Fractal Wick）

**黄金重合位（Magic 295）：**
- 价格实体跌破 0.41 + 强位移 → 上方留下未缓解订单块
- 局部斐波那契的 50% 位置与整体 range 的 0.295 完美重合
- 此处盲挂，浮亏极小（案例中仅 2.25 点），随后启动大波段

---

## 六、盲挂 vs 确认型进场

**盲挂（Blind Limit）：**
- 在 GB 级别直接挂限价单
- 前提：多重共流确认，心理能承受浮亏

**确认型替代方案：**
1. 等极限引线收出来
2. 量出引线的 50% 位置
3. 等价格回踩 50%，在引线高/低点外挂 Buy/Sell Stop
4. 止损设在引线极值外
