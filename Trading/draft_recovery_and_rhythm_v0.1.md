# DRAFT — Recovery & Rhythm Rules (恢复与节奏规则)
# Status: DRAFT v0.1 — independent draft, NOT merged into main material library
# Created: 2026-06-14 by Dragon
# Source inspiration: Kyle Ng / JadeCap (burnout, recovery, detachment, edge decay, pause rules)
# Core philosophy: 把"长期可持续"写成制度,不靠意志力 — 与现有"递进冷静期"同源
# ⚠️ Pending Chairman review. Do not treat as execution standard.

---

## 目的
当前体系已管住"单笔崩坏半径"(止损 + 冷静期 + 每天最多亏3次),
但没管"长期人的可持续":连续亏损周、达标后过度交易、长期 burnout、edge 衰减。
Kyle 靠自律解决这块;总裁的风格是把它**写成规则**,反而比他更稳。

这是共有维度里你唯一明显的缺口 —— 用你最擅长的方式(制度化)补上。

---

## 一、日内节奏(已存在,在此引用,不重复定义)
- 递进冷静期:1次亏→15min,2次→1h,3次→4h
- 每天最多亏3次,第3次后当天停止
- (本草案不改动以上,只在其上叠加"周/月"层)

---

## 二、周级节奏规则(草案 — 待 Chairman 定阈值)
**减速 / 停手(防连续崩坏):**
- [ ] 单周累计亏损达账户 Max DD 的 ___%(建议 50%)→ 当周剩余时间只 SIM,不实盘
- [ ] 连续 ___ 个交易日亏损(建议2)→ 强制休息1日,只复盘不下单

**达标后收缩(防贪 / 防回吐):**
- [ ] 达到当周盈利目标后 → 当周剩余交易减半手数(对接动态仓位"拉手刹")
- [ ] 单日达到当日目标 → 当日停止开新仓(锁定成果)

---

## 三、恢复机制(草案 — 把 Kyle 的"主动恢复"制度化)
- [ ] 每周固定 1 个完整休息日(不看盘、不复盘)— 防慢性 burnout
- [ ] 连续盈利后也设"降速点":避免顺风时过度自信扩大风险
- [ ] 情绪日志(可选):每笔交易后记录情绪状态,周末汇总,识别情绪化模式
  - 这是 Kyle 的"emotional journaling",和我们"复盘标准"待补项天然衔接

---

## 四、Edge 衰减监控(草案 — edge 会腐烂)
- [ ] 每月复盘:统计各策略胜率/盈亏比,若连续 ___ 周低于基准 → 标记该 edge 衰减
- [ ] 衰减的策略 → 转入 SIM/shadow(对接"多策略分布式架构"),不在实盘消耗
- [ ] 不 strategy hopping:衰减不等于立即换,先确认是市场状态还是 edge 本身失效

---

## 五、与系统理念的衔接
- 与"减少人为介入"一致:节奏/恢复规则一旦定死,系统可自动提醒/锁定,不靠总裁当场意志。
- 与"安全窗口"一致:这些规则属于 pre/post-market 检查,不在 live 交易时临场决定。
- 与"多策略分布式"一致:衰减策略降级到 shadow,是该架构的自然用途。
