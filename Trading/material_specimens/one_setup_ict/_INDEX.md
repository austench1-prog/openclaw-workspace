  - 2nd entry confirmation → **BREAKER**（破坏块：前一个失效的做多 OB，变为做空阻力）
- **止损：** 高点之上 或 INVERSION 区之上
- **ICT Macros（纽约时间）：**

- **进场规则：**
  1. K 线收盘跌破 IFVG 低点 → 下一根 K 线开盘进场
  2. K 线收盘跌破 BREAKER 低点 → 下一根 K 线开盘进场
- **目标：** 1:2 盈亏比

## 体系衔接（与我们的素材库对照）

| ICT 术语 | 我们的对应 |
|---|---|
| INVERSION (IFVG) | 反转 FVG（价格穿越后方向翻转的 FVG） |
| BREAKER | OB++ 失效后转为反向阻力 |
| Macro Time Window | ICT KillZone（我们的 TNTL 对应窗口） |
| Stop Hunt | Sweep（流动性猎杀） |
| premium PD array | 高溢价端 PD 阵列（做空的位置选择依据） |

**注意：** 本图为做空方向示意；做多镜像结构同理（discount PD array + 低点 stop hunt + INVERSION/BREAKER 向上确认）。

---

## 使用纪律
- 必须在 ICT Macro 时间窗内（不在窗口内的进场无效）
- Stop Hunt 是前提条件（没有猎杀就没有此 setup）
- INVERSION 或 BREAKER 二选一，不叠加（单一确认信号足够）
- 止损硬性放在猎杀高点之上或 INVERSION 区上方
