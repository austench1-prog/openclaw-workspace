# 素材类目：三振反转（Three-Strike Reversal / 震荡区间三振做空）

**类目创建：** 2026-06-18
**核心原则：** 震荡局面下，在每个新高尝试反向（做空），而不是追突破。掌握 ABC 两路径，避免陷阱。

## Specimen 列表

### S001 — 2026-06-18 · 震荡三振 + ABC双路径（标准教学图）
**文件：** `2026-06-18_three_strike_choppy_abc_specimen1.jpg`
**原稿：** `austin_raw_archive/2026-06-18/_RAW.md` [13:43 PDT]
**图表特征：**
- 左下角 CHoCH 确认后，市场开始震荡
- **1, 2, 3**（白色数字）= 三次向上冲高均受阻，标准三振走势
- **白色 A, B, C（区域级）：** A 为 OB 框，B 未超过 A，C 为更高点 → 三振结构
  - 路径一（白色 C 为顶）：直接向下至 MSA 均线（蓝色大箭头）
  - 路径二（红色延伸）：白色 C = 红色 B，再有一次向上冲红色 C，然后才下破至 MSA
- **MSA 均线：** 下方白色斜线（最终目标区域）

**核心教训（Chairman 原话提炼）：**
- 震荡中「突破 ≠ 继续上行」，「突破 ≠ 反转」——两个方向都不要轻易下判断
- 每次到最高点→尝试做空才有机会；当然也可以完全不操作
- 这种形态市场上非常多，是高频陷阱，掌握后可**大面积避免亏损**
