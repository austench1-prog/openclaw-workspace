## ⭐ MFF Rapid 通过路线图 (3 天方案 · 仅适用 MFF)

> ⚠️ **仅适用 MFF。不可直接套用于 TPT** — 两平台 50% 一致性相同,但**最低交易日不同**,路线图必须分别重算。

**一致性数学(锁定,与 TPT 算法一致):**
- 规则:单日盈利 ≤ 总盈利 × 50% → 反推 **总盈利 ≥ 最大单日 × 2**,且 ≥ $3,000。
- **2 天通过 ≈ 不可能:** 两天必须分毫不差相等。实操不可行。

**✅ 3 天方案(每日上限 $1,600):**

| 交易日 | 目标 | 累计 | 说明 |
|---|---|---|---|
| 第 1 天 | **~$1,600**(不超) | $1,600 | 已完成 2026-06-16 (045: +$1,481 / 046: +$1,476) |
| 第 2 天 | **~$1,600**(不超) | $3,200 | 待执行 → 总额超 $3,000,提前达标 + $200 缓冲 |
| 第 3 天 | **有交易即可(亏赢都行)** | — | 凑第 3 个交易日。第3天风控 = **最大亏损 ≤ $200**(动态风控,见 R-T3) |

- $1,600 优于 $1,500:两天即达 $3,200(超目标 $200 缓冲),不依赖第 3 天补足。

**🚨 红线:第 1、2 天任一天都不能 > $1,600**(否则那天 > 总额 50%)。今早 045/046 $1,481/$1,476 卡线下 ✅。

**风控触发逻辑(待落地;动态,按 R-T3 逐日计算):**
```

if mff_daily_pnl >= 1600 * 0.90:  发警告("接近 $1600")
if mff_daily_pnl >= 1600:         FLATTEN_ALL()
# 第3天 (已达 $3,200,风控转为限亏)
```
