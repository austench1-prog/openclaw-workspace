**Drawdown 类型说明：**

| 类型 | 底线变动 | 危险程度 | 代表平台 |
|---|---|---|---|
| Static | 永不移动 | 最低 | TradeDay |
| EOD Trailing | 只在收盘后移动 | 中 | MFF, TPT Prime |

## 龙哥自动执行规则

```
if 当日 P&L >= 日盈限制:
    FLATTEN_ALL  # 立刻平仓

if 当日 P&L <= -(日亏限制 × 0.8):
    发警报 → 总裁确认是否停手

if 净值 <= Drawdown Floor + $100:
    发紧急警报 → 强制 FLATTEN_ALL
```
