## 一、总结构

| 维度 | 系统一：自有资金系统 | 系统二：Prop Firm 经营系统 |
|---|---|---|
| **定位** | 投资系统 / 资本增值 / 长期能力 | 经营性现金流 / 类工资 / APM 收入 |
| **组成** | SPX $30K + 期货 $6K | 考试账户 + funded账户 + payout流程 |
| **本质** | 资本怎么增长、策略怎么成熟 | 账户池怎么运转、payout怎么稳定 |
| **类比** | 不是工资系统 | 更像一份业务，不是一笔投资 |

## 二、自有资金系统蓝图

### 目标函数
- 一级：保本金 / 提净值 / 控回撤
- 二级：固化 SPX 策略 / 固化期货执行 / 建立自动化能力
- 三级：为更大资金量和更高自动化做好准备

### 内部结构

**A. SPX 模块（$30,000）**
- 定位：主利润引擎，资本增长主轴
- 只做最成熟的 SPX 策略，独立风控
- 不承担补贴 Prop Firm 的任务
- 不是日常提款机

**B. 自有资金期货模块（$6,000）**
- 定位：策略验证场 + 执行系统试验场
- 验证 setup识别 / 执行Agent / 风控闸门
- 短期不是为了赚最多钱，而是为了把交易能力系统化

### 核心原则
1. 以资本增长为主
2. SPX 与期货分开管理
3. 期货优先服务于系统建设
4. 收益优先留在系统里复利
5. 不以"月月提款"作为首要目标

### KPI
- ✅ 净值增长 / 最大回撤 / 风险收益比 / 策略一致性 / 自动化成熟度
- ❌ 不优先看月度固定提款 / 不承担 APM 现金流责任

## 三、Prop Firm 经营系统蓝图

### 目标函数
- 一级：建立稳定 payout 节奏，建立可持续运转账户
- 二级：账户池不断档，形成"考试→通过→payout→再扩张"循环
- 三级：不破坏现金流的前提下扩大账户规模

### 内部结构（$4,000 分三层）

| 层次 | 定位 | 任务 |
|---|---|---|
| 主力账户池 | 购买主力考试账户 | 建立第一批 payout 生产账户 |
| 周转补充层 | 补位、替换、续接 | 防止账户池断档 |
| 扩张储备层 | 主力池稳定后才动用 | 提高未来现金流上限 |

### Payout 分流规则
| 部分 | 用途 |
|---|---|
| 第一部分 | APM 收入（工资来源）|
| 第二部分 | 账户池再投资（替换/扩张）|
| 第三部分 | 安全留存（系统韧性）|

### 最优路径
```
主力池建立 → 形成 payout → payout 分流 → 滚动扩张
```

### 核心原则
- 不再需要测试平台，核心是账户池运营
- 不一开始满铺，也不过度保守
- 建立节奏比快速扩张更重要

### KPI
- ✅ 可持续 payout 账户数 / 月度 payout 总额 / 账户池存活率
- ✅ 单位启动资金→账户容量 / 各平台净 payout 效率 / 流程错误率
- ❌ 不只看"开了多少账户"或"通过过多少"（通过≠能持续提款）

## 四、双系统边界

| 边界类型 | 规则 |
|---|---|
| 资金 | 分账管理，禁止互补 |
| 风险 | 自有资金重长期复利，Prop Firm 重连续性 |
| 考核 | 分别用不同 KPI，不混用 |
| 心理 | 自有资金关注成长，Prop Firm 强调纪律/节奏/产出 |

**禁止：**
- 自有资金补 Prop Firm 经营失误
- Prop Payout 掩盖自有资金问题

---

## 五、双系统协同

| 协同层 | 共享 | 独立 |
|---|---|---|
| 策略 | 期货模板可共享 | Prop Firm 按规则独立适配 |
| 技术 | 执行Agent / 风险观察Agent / 信息流程Agent | 参数分开 |
| 数据 | 标签体系 / 复盘框架 / 绩效分析 | 账户核算独立 |

---

## 六、平台服从计划原则

> 如果当前平台不适合目标，就换平台，不改变目标。

- 自有资金：期权/期货平台服务于未来自动化目标
- Prop Firm：平台已成熟，重点是账户池配置和现金流经营

## 七、阶段路线图

| 阶段 | 主要任务 |
|---|---|
| Phase 1 | 定性：确认两套系统，写清楚边界/KPI/收益用途 |
| Phase 2 | 落地：SPX/期货固化 + 账户池结构建立 |
| Phase 3 | 接入：统一执行/风控Agent，参数分离 |
| Phase 4 | 扩张：提高资本效率 + 扩大账户池 |
