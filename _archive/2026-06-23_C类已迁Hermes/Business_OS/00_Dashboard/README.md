## ⚠️ 安全架构：三层存储法（核心原则）

> **OpenClaw / 龙大哥接触不到原始敏感文件。Obsidian 只存管理逻辑，不存数据原件。**

| 层级 | 存放内容 | 工具 |
|---|---|---|
| **第一层：核心机密** | EIN / 银行开户文件 / 注册证书 / 税务回函 / 政府 ID | macOS 加密磁盘 / 1Password / Bitwarden |
| **第二层：管理流程** | 进度记录 / SOP / 合规清单 / 时间表 / 索引 | **Obsidian（本文件）** |
| **第三层：执行模板** | 商务信函模板 / 脱敏说明 / 话术框架 | **OpenClaw workspace（龙大哥）** |

### 关联方式
Obsidian 笔记里只写文件位置，不写文件内容：
> 例：「公司章程原件存放在本地加密盘 Documents/Corporate/APM_LLC/」

### 什么绝对不放进 OpenClaw workspace
- ❌ EIN 原始文件
- ❌ 银行账号 / 密码
- ❌ 政府 ID
- ❌ 税务申报原件
- ❌ 签字版 PDF

### 什么可以放进 OpenClaw workspace
- ✅ 商务信函模板（脱敏）
- ✅ 银行开户话术框架
- ✅ LLC 运营逻辑说明
- ✅ 合规流程说明
- ✅ 交易风险管理规则描述
